# 3. Logged channels

_Generated by `lab/generate.py` from the current data (20 flights). Do not edit by hand._

Every flight file holds **680 channels** (plus `t` and `label`). **329** of them change during at least one flight; the other 351 are constants (geometry, limits, settings) and are kept only for completeness. The viewer lists the changing ones; tick *list constant channels too* to see all.

Channel name prefixes:

| Prefix | What it is |
|---|---|
| `sensor/` | What the sensors READ, i.e. what the autopilot uses (and an FDR records): true value + observation anomaly + noise |
| `ap/` | Autopilot commands BEFORE any control anomaly, and its internal altitude target |
| `sel/` | Flight plan: selected altitude, CAS, heading, Mach |
| `derived/` | Computed from JSBSim internals (EGT law, not exposed as a property) |
| anything else | A JSBSim property: the TRUE simulated state (`[0]` is written explicitly for the first engine / tank) |

`context` = environment or bookkeeping channel: it can change after an anomaly only because the aircraft is somewhere else (different altitude -> different wind/air density). The viewer leaves these out of the "most affected" ranking by default.
